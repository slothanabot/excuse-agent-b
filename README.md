## How it works

`main.py` writes that single line to `/output/entry.txt`, after checking
it against the bounty gate: UTF-8 text, 1–200 characters, not only
whitespace, exactly one line. It then re-reads the file to verify what
actually landed on disk.

Run it with:

```sh
python3 main.py
```
